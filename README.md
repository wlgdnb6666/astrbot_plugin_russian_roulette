# AstrBot 俄罗斯转盘 🔫

基于 QRSpeed 脚本逻辑移植的 AstrBot (v4+) 群聊决斗游戏插件。

## 🕹️ 游戏规则
1. **发起**：使用 `/俄罗斯转盘 @某人` 向群友发起挑战。
2. **接受**：被挑战者回复 `/接受决斗` 即可开始。
3. **玩法**：系统模拟 6 弹槽左轮，只有一发子弹。双方轮流发送 `/开枪`。
4. **结局**：随着子弹被击发的次数增加，中弹概率会越来越高，第 6 枪必响。

## 📋 指令表
| 指令 | 描述 |
| :--- | :--- |
| `/俄罗斯转盘 @用户` | 发起一次决斗挑战 |
| `/接受决斗` | 开始游戏（仅限被挑战者） |
| `/拒绝决斗` | 取消挑战（仅限被挑战者） |
| `/开枪` | 轮到自己时执行，扣动扳机 |
| `/我的战绩` | 查看个人胜负场数和胜率 |
| `/终止决斗` | 强制终止当前群的决斗状态 |

## 📦 安装
在 AstrBot 管理面板的插件管理中，填写本仓库的 GitHub 链接即可。
