# 🔫 AstrBot 俄罗斯轮盘：决斗 (Duel)

[![AstrBot](https://img.shields.io/badge/AstrBot-v4.9.2+-orange?style=flat-square)](https://github.com/AstrBotDevs/AstrBot)
[![Version](https://img.shields.io/badge/Version-v1.2.1-FDD835?style=flat-square&labelColor=black)](https://github.com/AstrBotDevs/AstrBot)

一款为 AstrBot 深度定制的高互动性竞技插件。由 **青禾遇海** 提供核心创意文案，将惊险刺激的轮盘博弈带入群聊。

---

## ✨ 核心特性

- **📈 实时概率系统**：彻底告别简单的次数统计。系统根据弹巢残余空间，实时计算每一枪的**当前命中率**及**下一发预测概率**。
- **🎮 三大竞技模式**：
  - **普通模式**：标准 1/6 概率，最纯正的勇气试炼。
  - **双弹模式**：装填 2 颗子弹，博弈节奏翻倍，适合硬核玩家。
  - **自杀模式**：无需对手，随时随地开启单人试胆挑战。
- **🏳️ 认输机制**：在开枪前的生死关头可选择 `/认输`。虽然会记录一次败场，但生命高于一切。
- **📊 战绩存证**：本地化存储每位玩家的胜负场数及胜率，支持实时查询个人生涯数据。
- **📜 深度文案库**：内置 100+ 条由 **青禾遇海** 精心策划的随机文案，涵盖了从“死神擦肩而过”到“灵魂华丽谢幕”的各种场景。

---

## 🕹️ 指令速查

| 指令 | 目标 | 效果描述 |
| :--- | :--- | :--- |
| **`/决斗 @用户`** | 指定对手 | 发起 1 颗子弹的普通决斗 |
| **`/决斗 @用户 双弹`** | 指定对手 | 发起 2 颗子弹的极速决斗 |
| **`/决斗 自杀`** | 无 | 开启单人试胆挑战 |
| **`/接受决斗`** | 被挑战者 | 确认加入死斗 |
| **`/开枪`** | 当前玩家 | 扣动扳机，展示实时命中概率 |
| **`/认输`** | 当前玩家 | 终止游戏，记录一次败场 |
| **`/我的战绩`** | 无 | 查看胜场、败场及实时胜率 |
| **`/终止决斗`** | 管理员 | 强制清除当前群聊的游戏状态 |
