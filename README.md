# AstrBot 俄罗斯转盘 🔫

基于 QRSpeed 逻辑移植的 AstrBot (v4+) 群聊决斗插件。

## 🕹️ 游戏说明
1. 玩家 A 使用 `/俄罗斯转盘 @玩家B` 发起挑战。
2. 玩家 B 回复 `/接受决斗`。
3. 系统模拟左轮手枪（6 弹槽，1 发子弹）。
4. 双方轮流使用 `/开枪`。随次数增加，中弹概率越高，第 6 枪必响。

## 📋 指令列表
| 指令 | 功能 |
| :--- | :--- |
| `/俄罗斯转盘 @某人` | 发起决斗挑战 |
| `/接受决斗` | 开始游戏 |
| `/拒绝决斗` | 拒绝挑战 |
| `/开枪` | 扣动扳机 |
| `/我的战绩` | 查询个人胜率 |
| `/终止决斗` | 强制清空当前群游戏状态 |

## 📦 安装
在 AstrBot 插件管理面板中输入：
`https://github.com/您的用户名/astrbot_plugin_russian_roulette`
